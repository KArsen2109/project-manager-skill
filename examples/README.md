# Example: a standard-scope project

This shows the files the skill produces for a `standard`-scope project
called `survey-data-cleanup`, after founding and planning are done and
one stage of execution is complete. All content is illustrative —
replace with your own project's language and material.

- `survey-data-cleanup-state.md` — current position (Layer 0)
- `survey-data-cleanup-founding.md` — immutable decisions (written once)
- `survey-data-cleanup-plan.md` — the three plans (content/format/work)
- `survey-data-cleanup-log.md` — changelog, newest entry on top
- `survey-data-cleanup-cleaning-report.md` — one deliverable file

In a real workspace these files sit together inside the project's
folder, e.g. `Research/survey-data-cleanup/`. This example uses plain
filename references throughout (the default); see §2.3 in `SKILL.md`
for the optional wikilink variant.
